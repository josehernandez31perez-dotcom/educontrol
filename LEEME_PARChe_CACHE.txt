PARCHE DE CACHE PARA EDUCONTROL
Versión: 20261127a

Contenido: únicamente páginas HTML con versiones añadidas a las referencias locales
de archivos JavaScript y CSS. No incluye ni reemplaza PHP, SQL, JavaScript, CSS,
configuración ni datos.

INSTALACIÓN:
1. Conserva el respaldo que ya hiciste.
2. Cierra las pestañas de EduControl.
3. Extrae el contenido de este ZIP directamente dentro de:
   C:\xampp\htdocs\educontrol
4. Acepta reemplazar los archivos HTML.
5. Abre http://localhost/educontrol/ y comprueba las secciones.

NOTA:
Cuando se publique otra actualización de archivos JS/CSS, cambia el identificador
de versión en las referencias HTML para forzar al navegador a descargar los archivos nuevos.
Este parche no activa la conexión MySQL ni ejecuta migraciones SQL.
