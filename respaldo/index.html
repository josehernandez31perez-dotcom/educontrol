Descarga un archivo JSON con estudiantes, materias y calificaciones (formato versión 2).

El archivo no incluye usuarios ni contraseñas. Al importarlo, los usuarios actuales se conservan.

Importar respaldo

Reemplaza los datos actuales por los del archivo. Antes de hacerlo se pedirá confirmación.

Ningún archivo seleccionado.

    Cómo funciona

    • Esta sección es exclusiva del administrador. Otros roles no pueden acceder a ella ni exportar datos.
    • El archivo versión 2 no contiene usuarios ni contraseñas. Si se importa un archivo sin usuarios, los usuarios actuales se conservan.
    • Los archivos de versión 1 siguen siendo importables. Si incluyen usuarios, estos reemplazan a los actuales.
    • El archivo se revisa completo antes de cambiar nada. Si tiene errores, se muestra la lista de problemas y los datos actuales no se tocan.
    • Antes de reemplazar los datos se pide confirmación, con las cantidades actuales y las del archivo.
    • Si el navegador rechaza la escritura, se restauran los datos anteriores automáticamente.
